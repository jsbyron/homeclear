# Homeclear — First-Time Homebuyer Readiness Portal

Homeclear is a full-stack web application that helps first-time homebuyers assess their financial readiness to purchase a home. Users enter their income, savings, existing debts, and a target home price to receive an instant readiness score, cost breakdown, savings timeline, and an AI-generated personalized advisory summary.

## Features

- **Readiness Score** — A 0–100 score based on DTI ratio and down payment percentage
- **DTI Analysis** — Debt-to-income ratio with color-coded status (green / yellow / red)
- **Cost Breakdown** — Estimated monthly mortgage, taxes, insurance, PMI, HOA, and maintenance
- **Savings Timeline** — Months to reach FHA-eligible (3.5%) and conventional (20%) down payment thresholds
- **Live Mortgage Rate** — Fetches the current 30-year fixed rate from the FRED API (falls back to 6.85% if unavailable)
- **AI Advisor Summary** — Personalized 3–4 sentence plain-English advisory generated by Google Gemini
- **Assistance Programs** — Highlights FHA, VA, USDA, and state/local programs the buyer may qualify for
- **Resources** — Curated links to CFPB, HUD, VA, and USDA homebuyer guides

## Local Setup

### Prerequisites

- Node.js 18+ and npm
- A [Google Gemini API key](https://aistudio.google.com/app/apikey) (required for the AI summary feature)
- A [FRED API key](https://fred.stlouisfed.org/docs/api/api_key.html) (optional — enables live mortgage rate; falls back to 6.85% without it)

### 1. Install frontend dependencies

```bash
npm install
```

### 2. Install backend dependencies

```bash
cd server
npm install
cd ..
```

### 3. Configure environment variables

Copy the example file and fill in your keys:

```bash
cp server/.env.example server/.env
```

Edit `server/.env`:

```
GEMINI_API_KEY=your_gemini_api_key_here
FRED_API_KEY=your_fred_api_key_here   # optional
PORT=3001
```

### 4. Run both servers together

From the project root:

```bash
npm run dev
```

This starts the React frontend on `http://localhost:3000` and the Express backend on `http://localhost:3001` concurrently.

### Running separately

```bash
# Frontend only
npm start

# Backend only
npm run server
```

## API Endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/api/mortgage-rate` | Returns current 30-yr fixed rate from FRED or fallback |
| POST | `/api/summary` | Accepts `{ formData, results }`, returns AI advisory summary |

## Notes

- All calculations are estimates for educational purposes only and do not constitute financial or legal advice.
- The AI summary requires the backend to be running with a valid `GEMINI_API_KEY`.
- The app uses Create React App's dev proxy (`"proxy": "http://localhost:3001"`) to forward API calls during development.
